# Portfolio 2026

Portafolio personal desarrollado con React, TypeScript y Tailwind CSS.

## Stack

- **React 19** con TypeScript
- **Vite** como build tool
- **Tailwind CSS v4** para estilos
- **Motion (Framer Motion)** para animaciones
- **Blaze Motion** (librería propia) para presets de animación

## Proyectos

- **Blaze Motion**: Librería de animaciones open source
- **Dulces Ideas**: Sistema POS con modo offline-first
- **Worklyst**: Plataforma de gestión con agente de IA

## Comandos

```bash
# Instalar dependencias
bun install

# Ejecutar en desarrollo
bun run dev

# Build de producción
bun run build

# Previsualizar build
bun run preview
```

## Estructura

```
src/
├── components/    # Componentes reutilizables
├── data/projects/ # Datos de proyectos
├── lib/           # Constantes y tipos
└── sections/      # Secciones de la página
```
